# 🛢️ Rate of Penetration (ROP) Prediction Using Machine Learning

A machine learning application that predicts the **Rate of Penetration (ROP)** in drilling operations using drilling parameters, feature engineering, and unsupervised learning to support data-driven drilling analysis.

## 📋 Overview

This project develops an end-to-end machine learning workflow for predicting drilling Rate of Penetration (ROP) from operational parameters.

The system combines data preprocessing, feature engineering, K-Means clustering, and Random Forest regression to model the relationship between drilling conditions and penetration rate. A user-facing application makes predictions accessible without requiring direct interaction with the training code.

### Key Components

- **Data Preprocessing:** Cleans drilling data and prepares it for model training.
- **Feature Engineering:** Creates additional features and ratios from drilling parameters to represent their relationships.
- **Anomaly Analysis:** Includes utilities for identifying anomalous observations in the dataset.
- **Drilling Regime Clustering:** Uses K-Means to identify groups of similar drilling conditions.
- **ROP Prediction:** Uses a Random Forest Regressor to estimate penetration rate.
- **Interactive Application:** Provides a Streamlit interface for interacting with the trained model.

## ✨ Features

- 📈 **ROP Estimation:** Predicts drilling penetration rate from operational parameters.
- ⚙️ **Engineered Features:** Incorporates domain-relevant combinations and transformations of input variables.
- 🔍 **Operational Segmentation:** Uses clustering to represent different drilling regimes.
- 🌲 **Ensemble Regression:** Applies Random Forest regression to capture nonlinear relationships.
- 📊 **Model Evaluation:** Calculates RMSE, R², MAE, and MAPE.
- 🖥️ **Interactive Interface:** Makes model inference accessible through a web application.
- 📄 **Technical Report:** Includes a full project report describing the work.

## 🧠 Machine Learning Approach

### 1. Data Preparation

The workflow uses drilling measurements, including:

- **Depth TMD:** Measured depth.
- **Depth TVD:** True vertical depth.
- **RPM:** Rotary speed.
- **WOB:** Weight on bit.
- **Flow In:** Drilling fluid flow rate.
- **ROP:** Rate of Penetration — the prediction target.

The preprocessing workflow prepares the dataset, handles extreme target values, and creates additional features for modeling.

### 2. Feature Engineering

The model uses engineered variables derived from the original drilling parameters, including ratios, products, depth-related interactions, logarithmic transformations, and an energy-related proxy.

These features help represent relationships between operational conditions that may influence drilling performance.

### 3. K-Means Clustering

K-Means clustering is used to group observations with similar engineered feature values into drilling regimes. The resulting cluster assignment is incorporated into the regression model as an additional feature.

### 4. Random Forest Regression and Hyperparameter Optimization

A Random Forest Regressor is used to predict ROP by learning nonlinear relationships between drilling parameters and penetration rate.

The Random Forest model underwent multiple rounds of hyperparameter tuning to improve prediction quality. Model configurations were iteratively adjusted and evaluated to identify a more effective combination of parameters and enhance predictive performance.

### 5. Model Evaluation

The model is evaluated using several regression metrics:

R²: Measures the proportion of target variance explained by the model.

RMSE: Penalizes larger prediction errors.

MAE: Measures average absolute prediction error.

MAPE: Measures average absolute percentage error.
## 📊 Results

The project evaluates its regression model using multiple complementary metrics:

- **RMSE:** Root Mean Squared Error
- **R²:** Coefficient of Determination
- **MAE:** Mean Absolute Error
- **MAPE:** Mean Absolute Percentage Error

The evaluation results are generated by `train.py` and saved feature information is maintained in `stats.json`.

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or a compatible Python version
- Git
- pip

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Akchiche-Mohamed-Aymen/rop_prediction.git
```

**2. Navigate to the project directory**

```bash
cd rop_prediction
```

**3. Install dependencies**

```bash
python -m pip install -r requirements.txt
```

## 🖥️ Usage

### Step 1: Train the Model

Run the training script to preprocess the available data, perform clustering, train the Random Forest regressor, evaluate its performance, and generate model statistics.

```bash
python train.py
```

The repository includes saved model artifacts (`model.pkl` and `kmeans.pkl`) for use with the existing application, so retraining is not necessarily required before inference.

### Step 2: Launch the Application

Run the Streamlit application:

```bash
python -m streamlit run app.py
```

The application will open in your browser.

### Step 3: Use the Prediction System

Enter the drilling parameters requested by the application to obtain a ROP estimate.
